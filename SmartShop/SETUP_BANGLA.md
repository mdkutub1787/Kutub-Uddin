# SmartShop Admin Role System - Bangla গাইড

## 📖 ধারণা (সংক্ষিপ্ত)

- **নতুন ব্যবহারকারী** = স্বয়ংক্রিয়ভাবে `user` হিসাবে তৈরি
- **অ্যাডমিন কোড** লিখলে = `admin` এ উন্নীত হবে
- **Firebase** এ কোড সংরক্ষিত থাকবে

## ⚡ দ্রুত সেটআপ (৫ মিনিট)

### ধাপ ১: Firebase সেটিং (২ মিনিট)

1. **Firebase Console** খুলুন: https://console.firebase.google.com/
2. আপনার SmartShop প্রজেক্ট নির্বাচন করুন
3. **Firestore Database** এ যান
4. একটি নতুন **Collection** বানান: `settings`
5. একটি নতুন **Document** বানান ID: `admin_codes`
6. একটি **Field** যোগ করুন:
   - **নাম:** `codes`
   - **ধরন:** Array
   - **মান:** আপনার অ্যাডমিন কোড লিখুন (যেমন: "ADMIN_2024", "KEY_001")

উদাহরণ:
```
codes: [
  "ADMIN_CODE_2024",
  "SECRET_KEY_001",
  "MANAGER_CODE"
]
```

### ধাপ ২: অ্যাপে টেস্ট করুন (২ মিনিট)

1. অ্যাপ চালান
2. নতুন ব্যবহারকারী **রেজিস্টার** করুন
3. **Profile → "Request Admin Access"** এ ক্লিক করুন
4. Firebase থেকে অ্যাডমিন কোড লিখুন
5. সফল হলে: অ্যাডমিন ব্যাজ এবং অ্যাডমিন প্যানেল দেখা যাবে ✅

## 🎯 ব্যবহারকারী প্রবাহ

```
১. ব্যবহারকারী অ্যাপে রেজিস্টার করে
           ↓
২. সাধারণ ব্যবহারকারী হিসাবে তৈরি হয় (role: 'user')
           ↓
৩. Profile টিপে "Request Admin Access" দেখে
           ↓
৪. অ্যাডমিন কোড ইনপুট স্ক্রিন খোলে
           ↓
৫. Firebase থেকে কোড যাচাই করে
           ↓
৬. কোড ঠিক হলে: Admin এ উন্নীত হয় ✅
```

## 📱 অ্যাপে কী দেখা যাবে

### সাধারণ ব্যবহারকারী (User):
- ✅ Profile মেনু
- ✅ আমার অর্ডার
- ✅ Wishlist
- ✅ Settings
- ✅ **Request Admin Access** (নতুন!)
- ❌ Admin Panel

### অ্যাডমিন (Admin):
- ✅ Profile (Admin ব্যাজ সহ 👑)
- ✅ সব সাধারণ অপশন
- ✅ **Admin Panel** (প্রোডাক্ট, ক্যাটাগরি, অর্ডার ম্যানেজ করতে পারবেন)

## 🔑 অ্যাডমিন কোড পরিচালনা

### কোড যোগ করা (Firebase Console):
1. `settings` → `admin_codes` এ যান
2. `codes` array এ নতুন কোড যোগ করুন
3. Save করুন - **তৎক্ষণাৎ কাজ করবে!**

### কোড সরানো:
1. Array থেকে কোড ডিলিট করুন
2. সেই কোড আর কাজ করবে না

### কোড পরিবর্তন করা:
1. পুরনো কোড ডিলিট করুন
2. নতুন কোড যোগ করুন

## ⚠️ নিরাপত্তা টিপস

- অ্যাডমিন কোড **গোপন রাখুন** 🔐
- শুধু বিশ্বস্ত মানুষদের শেয়ার করুন
- Email/Chat এ পাঠাবেন না
- নিয়মিত কোড পরিবর্তন করুন

## 🆘 সমস্যার সমাধান

| সমস্যা | সমাধান |
|--------|--------|
| কোড কাজ করছে না | Firebase এ বানানো কোড চেক করুন, Spelling ঠিক আছে কি? |
| "Request Admin Access" বাটন দেখা যাচ্ছে না | ইউজার ইতিমধ্যে Admin হতে পারে |
| Admin Panel দেখা যাচ্ছে না | অ্যাপ সম্পূর্ণ বন্ধ করে আবার চালান |
| "Invalid code" এরর | কোড Firebase এ নেই বা Spelling ভুল |

## 🚀 সম্পূর্ণ ফ্লো

1. **Firebase সেটাপ** (২ মিনিট)
   - Collection বানান: `settings`
   - Document বানান: `admin_codes`
   - Admin কোড array এ যোগ করুন

2. **Security Rules যোগ করুন** (১ মিনিট)
   - `firestore.rules` ফাইল দেখুন
   - Firebase Console এ কপি পেস্ট করুন
   - Publish করুন

3. **অ্যাপ টেস্ট করুন** (২ মিনিট)
   - নতুন ব্যবহারকারী রেজিস্টার করুন
   - Admin কোড ভেরিফাই করুন
   - Admin Panel দেখুন ✅

4. **লাইভে যান** 🎉
   - সব কিছু ঠিক মনে হলে প্রকাশ করুন
